| **--gold** | Variable CSS para color dorado principal |
| **Backdrop-filter** | Efecto de desenfoque en el header |
| **Responsive** | Diseño adaptable a diferentes tamaños de pantalla |
| **Hover** | Efecto visual al pasar el mouse sobre un elemento |
